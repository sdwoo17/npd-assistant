# 가상 리테일미디어 연구 입력

이 파일은 코드 검증용으로 작성한 합성 자료다. 실제 쿠팡애즈 내부 문서, 사용자님의 독점 리서치, 실제 고객 조사 결과가 아니다.

소재 성과 비교는 지면·기간·타깃·비용을 함께 검토해야 한다는 가설을 세운다. 클릭 증가가 수익성 증가를 보장하지 않는다. 표본이 부족할 때 판단을 보류하는 이유를 광고주에게 설명할 필요가 있을 수 있다.

전담 분석가가 없는 소규모 광고주는 다음에 할 행동과 근거를 짧게 이해하고 싶어 할 수 있다. 대행사 운영자는 고객에게 변경 이유를 설명하고 승인 기록을 남겨야 할 수 있다. 두 유형의 요구가 다를 수 있으므로 가상 인터뷰로 질문을 탐색한 뒤 실제 광고주에게 검증한다.

소유자 전용 테스트 문구: RAW-ONLY-CANARY-7429. 이 문구는 공유 인사이트에 포함하지 않으며 PO 채팅의 모델 입력에도 전달하지 않는다.
