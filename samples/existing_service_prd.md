# 기존 상품 기획서 — 광고주 포털 성과 리포트 v0.1

**모든 내용은 공개 데모를 위해 만든 가상 자료입니다. 쿠팡애즈의 실제 기능·내부 PRD·로드맵을 설명하지 않습니다.**

## 대상과 문제

소규모 광고주와 대행사 운영자가 캠페인 및 소재별 성과를 확인하는 가상의 광고주 포털이다. PO는 리포트에서 정보를 찾는 과업을 개선하려고 한다.

## 가정한 현재 기능

- 기간·캠페인·소재 필터
- 노출·클릭·비용·전환·광고 귀속 매출 조회
- 소재별 CTR·CVR·ROAS와 이전 기간 비교
- CSV 다운로드

## 현재 기획의 공백

합계 지표의 순위는 제공하지만 지면·타깃·프로모션 차이는 설명하지 않는다고 가정한다. 소재 간 차이가 소재 자체 때문인지 설명하는 기능, 비교 가능한 조건 점검, 추가 실험을 제안하는 기능은 아직 기획되지 않았다. 이러한 공백이 실제 고객의 문제인지는 검증 전이다.

## PO가 다음 PRD에서 결정할 질문

1. 광고주가 원하는 것은 자동 소재 변경인가, 사람이 판단할 수 있는 설명인가?
2. 데이터가 부족하면 어떤 다음 행동을 제안해야 하는가?
3. 대행사가 고객에게 제안을 전달할 때 필요한 근거는 무엇인가?
4. 실제 통제 실험과 기존 성과의 단순 비교를 화면에서 어떻게 구분할 것인가?
