# PO 관점 시연

주제: 가상의 광고주 포털에서 소재 성과 해석과 다음 실험 제안을 기획한다. 쿠팡애즈 실제 내부 자료·고객 발언·경쟁사 사실로 설명하지 않는다.

## 입력 자료

| 파일 | 용도 |
| --- | --- |
| samples/research.md | 소유자 업로드와 인사이트 공개 범위 시연 |
| samples/voc.csv | 합성 상담 VoC 6건, 중복 처리 및 기능 연결 |
| samples/existing_service_prd.md | 가상 기존 리포트 기능과 기획 공백 |
| samples/proposed_service_prd.md | 사람이 만든 신규 서비스 PRD 기준 초안 |

demo 초기화에는 리서치·기존 기획서의 공개 인사이트, VoC, 두 페르소나가 들어 있다. 초기화는 이미 데이터가 있으면 덮어쓰지 않는다. 업로드를 직접 보여주려면 다른 제목으로 파일을 추가하고 인사이트 공개를 진행한다.

## 실제 모델 연결 전

1. 소유자 로그인 후 지식 관리에서 원문을 확인한다.
2. 공개된 인사이트와 비공개 원문이 서로 다른 자료임을 보여준다.
3. PO로 로그인해 지식 관리 메뉴가 없고 원문 API도 거절되는지 확인한다.
4. 고객 VoC의 “가상 샘플 6”을 확인하고 분류 하나를 바꾼다.
5. API 키가 없으면 채팅이 모델 미설정 오류를 표시하는지 확인한다.

## 실제 모델 연결 후

다음 질문은 현재 제공된 근거를 재료로 사용하는 예시이며 고정 답변 대본이 아니다.

1. “현재 가상 리포트 기능의 공백과 소재 분석 개선 기회를 리서치와 고객 VoC를 구분해 설명해 줘.”
2. “소규모 광고주와 대행사의 요구가 어떻게 다른가? 실제로 검증되지 않은 주장을 따로 적어 줘.”
3. 페르소나 화면에서 “분석가가 없는 소규모 광고주, 소재 분석 리포트”를 대상으로 AI 생성한다. 이미 같은 태그가 있으면 직접 정의 화면에서 다른 이름으로 저장한다.
4. “@소규모광고주 소재 추천에 비교 조건과 판단 보류 이유를 보여주면 어떻게 사용하시겠어요?”
5. “앞서 말한 가장 불편한 부분을 실제 업무 순서에 맞춰 더 설명해 주세요.”
6. “@대행사운영자 @소규모광고주 추천 근거와 고객 승인용 리포트 중 어느 쪽이 먼저 필요한가요? 서로 다른 의견도 설명해 주세요.”
7. “이번 대화에서 공통 요구·의견 차이·미검증 가설·실제 광고주에게 물어볼 질문을 정리해 줘.”
8. PRD 변경 제안을 생성하고 내용·근거를 확인한 후 채택 또는 보류한다.
9. 근거 패키지를 JSON으로 내려받는다. 공유 인사이트·VoC·가상 발언은 포함되지만 독점 원문은 포함되지 않는다.

## AXIOM과의 연결 지점

내보낸 JSON은 NPD 자체 규격이다. AXIOM 담당자에게 입력 규격을 확인한 뒤 변환기를 추가한다. 현 시연은 PO의 PRD 작성 재료가 만들어지는 과정까지이며 AXIOM에 자동 반영되는 시연은 아니다.

## 완료 기록

실제 시연에서는 모델 이름, 사용한 합성 자료, 질문, 답변 오류, PO의 제안 채택 이유를 기록한다. 모델 답변이 그럴듯해도 원문 보호·인용 정확성·광고주 업무 적합성을 각각 판단한다. 가상 FGI의 선호를 실제 고객 비율이나 실제 A/B 성과로 집계하지 않는다.
