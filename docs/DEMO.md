# 쿠팡애즈 PO 관점의 합성 서비스 시연

시연 대상은 **소재 성과 판단과 다음 실험 제안** 서비스의 기획 과정이다. 쿠팡애즈의 실제 기능·내부 PRD를 재현한다는 주장이 아니다. NPD 도구가 신규 서비스를 기획하는 과정이며, 광고 집행 또는 실제 A/B 통계 엔진을 실행하는 데모는 아니다.

## 준비

README대로 초기화한다. 소유자와 PO는 서로 다른 브라우저 프로필을 사용한다. `samples/research.md`, `samples/existing_service_prd.md`, `samples/features.json`, `samples/voc.csv`를 사용한다. `samples/new_service_prd_draft.md`는 참고용 기획 초안이며 모델 생성 결과로 표시하지 않는다.

데모 시드의 페르소나는 사람이 미리 작성한 합성 프로필이다. **AI 생성 기능은 별도로 실행**해서 새 레코드가 추가되는 장면을 보여준다. 실제 AI를 사용하려면 Bedrock 설정 후 `python scripts/live_validation.py --run`을 먼저 실행한다. 미설정 상태에서는 AI 질문이 실패할 수 있으며 고정 답변으로 대체하지 않는다.

## 1. 보호된 리서치 → 기획 질문

1. 소유자가 지식 관리에서 연구 파일을 업로드하고 AI 인사이트 초안을 추출한다.
2. 초안의 적용 조건·한계·연결 기능을 편집하고 공개할 카드만 체크해 일괄 공개한다.
3. PO는 원문 메뉴 없이 리서치 채팅에서 질문한다: “소규모 광고주의 소재 성과 리포트 개선 기회를 근거와 함께 설명해 줘.”
4. 인용 버튼에는 승인된 인사이트/VoC만 나타나는지 확인한다. 원문 전체를 요청해도 원문이 모델 입력에 들어가지 않아야 한다.

## 2. VoC → 기능과 검증할 문제

1. 소유자: 고객 VoC에서 기능 트리와 CSV를 가져온다. 같은 출처로 재업로드하면 모두 중복이다.
2. PO: 2026-08-01~2026-08-31, 소규모 광고주 등의 범위를 선택하고 분모를 확인한다.
3. AI 분류 실행 후 기능 연결·문제·요구를 검토하고 필요한 항목을 수정한다. 초기 규칙 분류를 정확한 정답으로 소개하지 않는다.
4. “현재 대화에 적용” 후 질문한다: “이 기간의 소규모 광고주 의견에서 소재 비교 조건을 확인하기 어려운 이유는?”

첨부된 별도 180건은 전부 합성이며 정답 기능 라벨이 없다. 정확도 시연을 하려면 PO가 별도로 라벨을 검토하고 실제 모델 분류와 비교해야 한다. 이 저장소에는 그 CSV 원문을 복제하지 않았다.

## 3. 페르소나 생성 → FGI → PRD v2

1. 채팅 동작을 “이 설명으로 페르소나 생성”으로 바꾸고 “전담 분석가가 없고 예산이 제한된 소규모 광고주”를 입력한다. 생성된 프로필의 관찰·추론·합성/실제 근거 수를 확인한다.
2. PO 결정에 “자동 소재 교체는 제외하고, 비교 조건과 판단 근거를 먼저 제공한다.”를 저장한다.
3. “@소규모광고주 @대행사운영자 추천 소재의 근거가 어떻게 보여야 적용하시겠어요?”라고 묻는다.
4. 라운드를 반박·조건 확인으로 바꾸고 “앞선 의견에 동의하지 않는 상황과 거절할 조건을 설명해 주세요.”라고 후속 질문한다.
5. 디브리프를 생성해 의견 차이·근거 부족·실제 고객에게 확인할 질문을 검토한다.
6. 기준 PRD를 선택하고 변경안을 생성한다. PO 결정·원본 메시지·근거 버전과 변경 전후 문구를 확인한다.
7. 문구를 수정하고 채택한다. PRD가 실제 새 버전으로 저장되는지, 같은 채택을 반복해도 버전이 추가되지 않는지 확인한다.
8. Markdown을 내려받아 `[ID]`와 근거 목록이 남는지 확인한다. AXIOM 붙여넣기 이후의 보존 여부는 쿠팡애즈 측에서 함께 검증한다.

## 4. 안전장치 확인

소유자가 인용된 인사이트를 철회한 뒤 PO가 대화를 새로 연다. 기존 산출물은 재확인 안내로 바뀌고, 그 근거에 의존한 제안·페르소나는 더 이상 사용할 수 없어야 한다. 새 프로젝트로 전환하면 기존 프로젝트의 자료가 나타나지 않아야 한다.

실제 광고주로 FGI를 한 것처럼 소개하지 않는다. 목적은 PO가 실제 인터뷰 질문과 PRD 가설을 더 체계적으로 준비할 수 있는지 확인하는 것이다.
