대상: `sdwoo17/npd-assistant`, `feature/research-workflow-v2`, PR #1. 기준 커밋은 `c4b7ea0`이다. 적용 명세는 사용자가 제공한 2026-09-13 요구사항·구현 정의서, 남은 작업 실행 계획, 도메인 검토 문서다. 독점 원문 및 사용자 자산은 공개 저장소에 포함하지 않는다.

## 도메인 자산으로 측정한 결과

기존 확보 ZIP과 이번 확보 ZIP의 전체 SHA-256이 일치했고 원본 파일 수는 31개였다. 변환된 비공개 팩의 소유자 자료 37개, 인사이트 초안 36개, 합성 VoC 240건, 프로필 8개를 별도 임시 DB에 적재했다. 자료 원문·질문 본문·답변은 저장소의 측정 결과에 포함하지 않는다.

| 검사 | 결과 |
| --- | --- |
| 승인 전 공개 인사이트 | 0개 |
| PO의 원문 접근 | 37개 모두 403 |
| 인사이트 승인 후 프로필 활성화 | 8개 생성; 재실행 추가 생성 0개 |
| 도메인 질문 8개 × 3회 | 모든 회차에서 지정 후보 중 최소 하나가 상위 24개에 포함 |
| 후보 첫 순위 | 질문 순서대로 5, 21, 21, 18, 1, 1, 20, 1 |
| MRR@24 | 0.4251 |
| 순위 반복 안정성 | 3회 동일 |
| 질문별 검색 중앙 지연 | 약 386~430ms, 이 로컬 276건 지식 규모에서 측정 |
| 8명 × 2라운드 | 가상 발언 16개 저장; 명시적 모델 테스트 대역 사용 |
| 디브리프·PO 결정·변경 채택 | 실제 PRD v2 생성 및 Markdown 생성 |
| 인사이트 철회 | 활성 프로필 0개, 노출 제안 0개 |
| 암호화 백업·새 폴더 복구 | 무결성·키 검증 성공; 자료 37개 보존 |

검색 후보셋은 작성자 정의다. 기존 도메인 검토에 기록된 4/8 대비 이번 측정은 8/8이지만 독립 정답셋의 정밀도나 실제 답변 정확도가 아니다. 후보가 18~21위에 머무는 질문도 있으므로 상위 순위·의미 품질 개선이 남는다. 합성 주석을 적재한 건수는 LLM 분류 정확도로 계산하지 않는다.

## 회귀 테스트

기준 Python 테스트는 110개였다. 추가 테스트는 검색 순서 안정성, 내용과 메타데이터 구별, 권한·철회, 문서 순서, 프로필 초안 활성화, 동시성·별칭 충돌·버전 충돌, 기존 팩 등록, 계정과 세션, 암호화 백업 변조·잘못된 암호·키 불일치, HTTPS 검사 도구를 다룬다. 실제 Chromium에는 소유자 승인→프로필 활성화→PO @질문의 경로를 추가했다.

최종 회귀 명령은 `python scripts/regression.py --passes 3 --browser`이다. 최종 로컬 실행에서 Python 130개, DOM+HTTP 2개, Chromium 7개를 각각 3회 통과했으며 각 회차의 원본 로그는 GitHub Actions의 `regression-results`에 남긴다. CI는 별도로 CloudFormation lint와 Docker 빌드·시작 검사도 수행한다. 정확한 공개 커밋과 CI 결과는 PR #1의 해당 실행을 기준으로 확인한다.

이 작업 환경에는 AWS 인증과 Bedrock 모델 ID, 실제 배포 도메인이 설정되지 않았다. 연결 검사는 `bedrock_not_configured`, 실환경 게이트는 `NOT_RUN`으로 확인했다. **코드·회귀 검증 완료를 실제 Bedrock 전체 흐름·HTTPS 서비스·고객 UAT 완료로 표시하지 않는다.** 다음 실행 순서는 AWS 인증 연결 → 실제 Bedrock 전체 흐름 검증 → HTTPS 배포 → PO 테스트이며 [운영 문서](PILOT_OPERATIONS.md)에 명령과 통과 기준을 제공한다.
