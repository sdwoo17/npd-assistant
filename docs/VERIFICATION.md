# 검증 결과와 남은 범위

검증일: 2026-09-12. 새 저장소의 로컬 MVP에 대한 결과이며 기존 CloudFront 사이트의 검증이 아니다.

## 실행 결과

| 검사 | 결과 | 실제로 확인한 범위 |
| --- | --- | --- |
| Python unittest | 31개 통과 | 서비스 22, HTTP 7, 모델 전송 계약 2 |
| JavaScript DOM + HTTP | 시나리오 2개 통과 | 실제 화면 코드와 실제 로컬 서버 연결 |
| Python compileall | 통과 | 애플리케이션 구문 검사 |
| node --check | 통과 | 화면 JavaScript 구문 검사 |

DOM 테스트는 jsdom에서 실제 app.js를 실행하고 임시 SQLite를 사용하는 HTTP 서버에 요청한다. 소유자 업로드→인사이트 공개, PO 기능 분류→@자동완성→복수 인터뷰→후속 질문→근거 확인→PRD 제안 채택을 검증했다.

모델 응답은 테스트 디렉터리의 RecordingModel 또는 로컬 가짜 Responses API가 제공한다. 테스트용 응답은 실행 앱에서 사용하지 않는다. 33개 검사가 실제 모델 품질 검증 33회를 의미하지 않는다.

## 보호·권한 검증

- 소유자만 원문 조회·인사이트 공개를 수행한다.
- PO 요청 본문의 role/project_id로 서버 권한을 바꿀 수 없다.
- 다른 프로젝트의 원문·대화에 접근할 수 없다.
- 원문만의 식별 문자열이 PO 초기 데이터·검색 근거·채팅 모델 입력·JSON 내보내기에 없다.
- 원문에 권한 변경 지시가 있어도 PO 모델 입력에 들어가지 않는다.
- 비공개 초안은 검색되지 않고 공개 철회는 과거 AI 답변·페르소나·제안 조회에 반영된다.
- 생성 도중 근거를 철회하면 해당 근거를 인용한 결과가 저장되지 않는다.
- 출처 ID를 모델이 창작하면 응답 저장을 거절한다. 인용 내용의 의미상 일치까지 자동 보장하는 검사는 아니다.
- 세션·로그아웃·만료·CSRF·Origin·Host·로그인 시도 제한을 검증했다.

## 요구사항 대비 현재 수준

| 영역 | 구현 | 남은 작업 |
| --- | --- | --- |
| 독점 리서치 | 업로드·텍스트 추출·암호화·초안·공개/철회·PO 채팅 | 문서 버전 UI, 처리 작업 재시도 관리, 세밀한 고객사별 공개 정책 |
| VoC | CSV·패턴 가명화·중복 처리·수동 보정 가능한 기능 분류·채팅 근거 | 실제 앱 출처 확정·수집 성공 검증·전체 페이지 수집·추가 개인정보 처리 |
| 페르소나 | 근거 기반 생성/직접 정의·가정·@태그·개인/복수 인터뷰 | 편집·버전 변경 이력 UI와 모델 응답 품질 검증 |
| PRD 연결 | 대화 기반 제안·근거/메시지 연결·채택/보류·JSON | 기존 PRD 문단별 수정 및 버전 관리, AXIOM 형식 변환/API |
| 실행 환경 | 로컬 Python 서버·SQLite·정적 웹 화면·CI 설정 | 운영용 서버·인증·암호화 키 관리·배포·실제 브라우저/광고주 UAT |

현재 결과를 전체 요구사항의 100% 구현 완료로 표현하지 않는다.

## 수행하지 않은 검증

- 실제 OpenAI 모델 호출: 실행 환경에 키와 모델 설정이 없어 미실시.
- 실제 Apple 리뷰 수집: 관리 앱 ID/토큰이 없어 미실시.
- 실제 AXIOM 수신·반영: 고객사의 API/교환 규격 미확인.
- 실제 브라우저의 시각적 배치·모바일·접근성: 원격 브라우저에서 로컬 주소 접근이 차단되어 미실시. DOM 테스트와 구분.
- 기존 CloudFront 배포 및 실제 PO·광고주 UAT: 미실시.

## 재현

~~~bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python -m compileall -q app manage.py
node --check static/app.js
npm ci --ignore-scripts
npm test
~~~

Node는 UI 테스트에만 필요하며 애플리케이션 실행 자체에는 필요하지 않다. GitHub Actions는 같은 검사를 실행하도록 설정되어 있다. 원격 실행 상태는 저장소 Actions에서 별도로 확인한다.
