# 0.2 구현·회귀 검증 기록

검토 기준: `main`의 `946a2a105a2917641492468053974e78b133ef54`와 사용자의 세 기능 요구사항 및 16개 수용 기준. 수정 브랜치: `feature/research-workflow-v2`. 검증일: 2026-09-12.

**정의한 자동 검증은 통과했지만 “100% 완벽한 제품”으로 판정하지 않는다.** 실제 AI 응답 품질, 광고주 표본의 대표성, AXIOM 수신 후 인용 보존, 기존 AWS 앱 통합과 공개 운영은 별도 검증이 남아 있다.

## 실행한 검증

| 검증 | 결과 / 범위 |

[반복 실행 요약](regression-summary.json)에 각 실행 시간과 반환 코드가 있다. 위 85/2/4는 서로 다른 테스트 수이며 반복 횟수를 새 시나리오 수로 부풀리지 않는다. 1,000행/300단계도 Python 테스트 안의 반복 사례로, 별도 1,300개 unittest라는 뜻이 아니다. 모델 응답은 회귀 테스트 안에서만 명시적인 test double을 사용하며 실행 앱은 이를 import하지 않는다.

실제 브라우저 시나리오는 소유자 파일 업로드→AI 초안→일괄 공개, PO 결정→복수 태그/반박→디브리프→PRD v2→Markdown 다운로드, 채팅에서 페르소나 레코드 생성→@자동완성→프로젝트 전환→근거 없음, 390px 화면과 마크업 비실행을 포함한다.

## 180건 사용자 제공 CSV 실측

첨부 CSV 원문은 저장소에 게시하지 않았으며 임시 DB에서 실행 후 제거했다. [집계 결과](benchmark-voc-180.json)에는 본문과 외부 ID가 없다.

- 최초 적재 **180건 / 중복 0 / 오류 0**, 약 **96ms**.
- 같은 출처 재적재 **추가 0 / 중복 180**.
- 전부 `synthetic`. 정답 기능 라벨이 있는 행은 **0건**.
- 기본 규칙의 주 기능: creative_test 60, reporting 25, budget 16, workflow 6, **미분류 73건(40.56%)**.
- 4개 질문을 각 20회 검색: 24건 반환, 중앙 지연 약 **27~28ms**, p95 약 **33~40ms**. 로컬 환경 수치이며 동시 사용자 부하나 관련성 정확도 검증이 아니다.

**규칙 분류의 정확도가 개선됐다고 주장하지 않는다.** 사용자가 보고한 재현율 0.53을 이 무라벨 파일로 재현할 수 없다. 프로젝트 기능 트리·AI 분류·PO 보정 경로를 구현했지만 실제 분류 품질 게이트는 PO가 판단한 정답 라벨과 실제 모델이 필요하다. 어휘 검색도 임베딩 검색으로 바뀐 것이 아니다.

## 수정 중 발견해 막은 회귀

- 기능 키워드의 단일 버킷 흡수를 복수 연결로 변경하고 AI·PO 분류 경로 추가.
- 원천 외부 ID 소실 및 출처:ID 문자열 경계 충돌 제거.
- PO 초기 발언/결정의 누락, 단순 상태만 바뀌던 PRD 채택을 실제 문단 변경으로 수정.
- 최종 인용에서 제외된 입력, 과거 대화, 집계 분모를 통해 남던 간접 지식 의존성 차단.
- 생성 중 철회·동시 수정·두 번째 페르소나 실패·DB 실패·중복 요청에서 부분 결과 저장 차단.
- 잘못된 빈 배열 날짜/필터 수용, 날짜 필터 때문에 리뷰 페이지 수집이 일찍 멈추는 결함 수정.
- 실제 Apple RSS 호출에서 `sortBy=mostRecent` 대소문자 계약을 확인해 빈 결과가 나오던 주소 오류 수정.
- 근거의 수치를 다른 단위로 바꾸는 응답 거절. 이는 문장 전체 의미의 자동 진실 판정이 아님.
- 버전 없는 이전 MVP 생성 산출물은 불완전한 provenance를 신뢰하지 않고 재확인 처리.

## 릴리스 판단

소스 변경과 명시한 자동 회귀는 완료 범위다. 고객 데모를 실제 AI로 완료했다고 판정하려면 모델 접근 권한이 있는 환경에서 live gate를 실행하고, 라벨 있는 실제/합성 평가 자료로 분류·검색·인터뷰 품질을 PO가 검토해야 한다. AXIOM과 기존 CloudFront 서비스는 [통합 지침](INTEGRATION.md)에 따라 별도 연계한다. 이 기록을 “100% 모든 경우를 검증했다”는 주장으로 사용하지 않는다.
