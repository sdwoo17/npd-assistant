대상은 `sdwoo17/npd-assistant`의 독립 Python/SQLite 파일럿이다. 기준은 PR #3이 병합된 main `5ec83e05f994ab48555c5232d0c0b64274b7d1c6`이다. 별도 React/Lambda/CDK 플랫폼의 기능·데이터·배포 기록을 이 저장소의 완료 증거로 취급하지 않는다.

FGI 가이드는 세션 구조·시간·워밍업을 하나의 항목으로 묶어 총 여덟 항목으로 정의한다. 별도 시연 문서의 ‘8절’ 설명에 나열된 아홉 주제를 누락하지 않기 위한 구성이다. 기존 요약+다섯 그룹 디브리프를 사용하며 별도 플랫폼의 8절 문서·PRD 마법사와 동일한 구현은 아니다.

인용 검사 수치는 제출한 텍스트와 현재 프로젝트에 한정된다. `[id] v2` 또는 `expected_versions`로 지정한 버전만 대조하며, 인용의 의미적 진실·AXIOM 실제 사용량·외부 전송 성공까지 입증하지 않는다. 식별할 수 없는 외부 PRD ID는 보존하되 유효하다고 표시하지 않는다.

## 검증과 공개 범위

새 테스트는 합성 자료와 `tests/helpers.py`의 명시적 모델 대역만 사용한다. 실제 리서치, 고객 로그, 비밀번호, 키, DB 및 세션을 코드나 CI 자료에 포함하지 않는다. 실제 모델 응답을 대역으로 대체하는 실행 기능을 추가하지 않는다.

- Windows Python 3.14 전체 실행: 179개 중 165개 통과, 실패 1개·오류 13개. 디렉터리 교체, 심볼릭 링크 권한, POSIX 파일 권한, 하위 프로세스 문자 인코딩 문제를 포함한다. 이후 수동 PRD 인용 회귀가 추가되어 CI 대상은 181개다.
- DOM/실제 로컬 HTTP: 기본 4개 통과 후, 철회된 프로필 관리 회귀를 추가했다. 새 스터디 완주, PRD 제안 및 프로젝트 변경 시 새 화면의 데이터 비우기를 포함한다.
- 공식 수용 기준: GitHub Actions의 Linux/Python 3.12·Node 22 전체 회귀, Chromium, 컨테이너·HTTP·인프라 검사. 최종 PR의 동일 코드 버전 결과로 판정한다.
- 실제 Bedrock 호출 품질, 운영 HTTPS, AWS IAM/백업 복원과 고객 수용은 별도 실환경 증거가 필요하다.

이 변경은 확인된 결함과 현재 코드에서 실행 가능한 연구 흐름을 보완한다. 전체 첨부 요구사항의 100% 완료, 배포 완료 또는 외부 플랫폼과의 동작 동일성을 선언하지 않는다.

최종 로컬 핵심 회귀는 수동 PRD 인용 추가 후 108개 모두 통과했다. JavaScript 구문 검사와 staged diff 검사는 통과했다.

최종 화면 검증에서 모바일 로그아웃 버튼 비노출과 페르소나 탭의 오래된 목록을 확인해 수정했다. 철회된 프로필도 내용 노출 없이 보관할 수 있으며, 전체 풀 수와 선택 가능한 프로필 수를 구분한다.
